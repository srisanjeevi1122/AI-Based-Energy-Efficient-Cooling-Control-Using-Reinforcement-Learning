# AI-Based-Energy-Efficient-Cooling-Control-Using-Reinforcement-Learning

## 📌 Overview
This project focuses on improving cooling system efficiency using Reinforcement Learning (RL). It compares DQN, PPO, and A2C algorithms in a simulated cooling environment to analyze energy consumption, temperature control, and learning stability.

## 🎯 Objective
To develop an intelligent cooling controller that reduces energy consumption while maintaining comfortable temperature conditions.

## ❗ Problem Statement
Traditional thermostat-based cooling systems lack adaptability to dynamic environmental conditions, which can lead to unnecessary energy consumption and inefficient temperature control.

## 💡 Proposed Solution
An RL-based cooling control system was developed to learn optimal cooling decisions through interaction with a simulated environment. Different RL algorithms were evaluated to identify their effectiveness in balancing energy efficiency and temperature comfort.

## 🤖 Algorithms Used
- DQN – Deep Q-Network
- PPO – Proximal Policy Optimization
- A2C – Advantage Actor-Critic

## 📊 Evaluation Metrics
- Total Reward
- Energy Consumption
- Temperature Control Performance
- Training Stability

## 🧪 Experimental Methodology
- Simulated cooling environment
- Neural Network architecture: 64-64
- Comparison with baseline cooling methods
- Multiple random seeds
- Wilcoxon statistical testing

## 🏆 Key Findings
The experimental results showed that A2C performed effectively in the evaluated cooling environment.

- 79% lower penalty compared to no cooling
- 13% better performance than the thermostat rule

These results highlight the potential of Reinforcement Learning for intelligent and energy-efficient cooling control.

## 🛠️ Technologies
- Python
- Reinforcement Learning
- Deep Learning
- Neural Networks
- Simulation-Based Evaluation
- Statistical Analysis

## 📌 Conclusion
This project demonstrates how Reinforcement Learning can improve cooling system decision-making by balancing energy consumption and temperature control. It also provides a comparative evaluation of different RL algorithms in a simulated environment.
